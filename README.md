# 遮影 GitHub Pages 試作版

## 上線方式
1. 在 GitHub 建立新的 Repository。
2. 將本資料夾內所有檔案上傳到 Repository 根目錄。
3. 進入 Settings → Pages。
4. Source 選擇 Deploy from a branch。
5. Branch 選 main，資料夾選 / (root)。
6. 儲存後即可取得 GitHub Pages 網址。
